# 순간카메라 (가칭) — 찍는 순간 공유되는 카메라

앱으로 사진을 찍으면 AI가 캡션을 붙여 인스타그램에 바로 올려 주는 웹앱(PWA)입니다.
휴대폰 브라우저에서 열어 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 들어 있는 기능

| 기능 | 설명 |
|---|---|
| 즉시 자동 게시 | 촬영 → 3~5초 취소 가능 시간 → 인스타그램 게시 |
| AI 캡션 | Claude가 사진을 보고 캡션·해시태그 작성 (게시 전에 고칠 수 있음) |
| 일상 / 레이스 모드 | 레이스 모드는 거리·시간·페이스·구간을 사진에 새겨 스토리로 게시 |
| 완주 후 묶음 게시 | '오늘' 화면에서 베스트 사진을 골라 피드에 한 게시물로 |
| 단체 사진 확인 | 얼굴이 2명 이상이면 게시를 멈추고 물어봄 |
| 오프라인 대기 | 신호가 없으면 휴대폰에 보관했다가 신호가 잡히면 자동 업로드 |
| 블로그 초안 | 하루치 사진·캡션을 시간순으로 모아 복사용 글 생성 |

## 폴더 구조

```
config/                  Django 설정, 주소 연결
camera/
  models.py              사진(Photo), 레이스(RaceSession), 게시 설정(AppSettings)
  views.py               화면 3개(촬영·오늘·설정)와 API
  services/
    caption.py           Claude API: 캡션 + 해시태그 + 인원수 (한 번의 호출)
    instagram.py         Instagram Graph API: 스토리 / 피드 / 묶음 게시
    publisher.py         게시 실행과 결과 기록
    images.py            사진 방향 보정, 크기 줄이기, 피드 비율 맞추기
    blog.py              블로그 초안 만들기
  static/camera/
    camera.js            촬영, 레이스 기록, 카운트다운, 오프라인 대기열
    today.js             '오늘' 화면 동작
  templates/camera/      화면 템플릿, 서비스 워커(sw.js)
  tests.py               자동 테스트 18개
```

## 내 컴퓨터에서 실행

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser   # 로그인할 계정 만들기
python manage.py runserver
```

`http://127.0.0.1:8000` 에서 로그인하면 됩니다. 테스트는 `python manage.py test`.

키를 넣지 않으면 **연습 모드**로 동작합니다. 인스타그램에 실제로 올리지 않고
올린 것처럼 기록만 남기므로, 화면 흐름을 마음껏 시험해 볼 수 있습니다.

## 실제로 쓰려면 (환경 변수)

`.env.example` 에 있는 값을 Render의 Environment 화면에 넣습니다.

1. `ANTHROPIC_API_KEY` — AI 캡션과 단체 사진 인원수 확인
2. `IG_USER_ID`, `IG_ACCESS_TOKEN` — 인스타그램 게시
   - 인스타그램을 크리에이터 계정으로 전환하고 페이스북 페이지와 연결
   - Meta 개발자 사이트에서 앱을 만들고 `instagram_content_publish` 권한의 장기 토큰 발급
3. `PUBLIC_BASE_URL` — 앱의 https 주소. 인스타그램이 이 주소에서 사진을 가져갑니다.

## Render 배포

`render.yaml` 이 들어 있어 Render에서 "New → Blueprint"로 이 저장소를 고르면 무료 플랜으로 만들어집니다.
데이터베이스는 SQLite(파일)를 쓰고 사진도 서버 안에 저장하므로, 서버가 쉬었다가 다시 깨어나면
(무료 플랜은 15분간 요청이 없으면 잠듭니다) **사진과 설정이 모두 사라집니다.** 화면 흐름과 AI 캡션을
시험해 보는 용도로 쓰시고, 실제로 계속 쓰실 때는 디스크와 데이터베이스를 붙인 유료 플랜으로 바꿔야 합니다.

## 알아 둘 점

- **거리 측정**: 웹앱은 화면이 꺼지면 위치를 받지 못합니다. 레이스 화면의 기록판을 눌러
  시계에 찍힌 거리로 맞출 수 있습니다. 시간은 화면이 꺼져도 정확합니다.
- **카메라·위치·홈 화면 설치**는 https 주소에서만 동작합니다 (내 컴퓨터의 127.0.0.1 은 예외).
- **스토리**에는 캡션이 붙지 않습니다 (인스타그램 API 제한). 레이스 기록은 사진에 새겨집니다.
- **페이스북·스레드 동시 게시**는 인스타그램 앱의 연동 설정을 따릅니다.
  API로 올린 게시물도 함께 올라가는지는 실제 계정으로 확인이 필요합니다.
